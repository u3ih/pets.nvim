## The cat

There is no `cat/` here. The upstream packs no longer ship one — the cat
credited to [SeethingSwarm](https://seethingswarm.itch.io/catset) in
giusgad/pets.nvim was removed, which is why that credit reads "the *old* cat
assets". The plugin draws a cat in ASCII instead, and that drawing is original
work covered by this repository's MIT licence.

To add a PNG cat, see "Adding your own species" in the README.
